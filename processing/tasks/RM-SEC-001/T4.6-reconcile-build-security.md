# T4.6 — Reconcile build-chain security findings

**Goal:** G4  
**Status:** Blocked by T4.5

## Scope

Run full/production audits, SBOMs, dependency scans, clean builds, package tests, and artifact inventories. Attribute removed findings to G4 and carry server/runtime findings into G5 without weakening the release gate.

## Exit condition

Obsolete build-chain high/critical findings and packages are absent; every residual finding is accurately assigned, and MI-P6 remains blocked while any high/critical production finding exists.

## Verification

Compare exact lock and advisory inventories against the G3 baseline, validate SBOMs, and scan both dependency graph and shipped artifacts.
