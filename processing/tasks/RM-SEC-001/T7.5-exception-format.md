# T7.5 — Advisory-exception format

**Roadmap:** RM-SEC-001 / G7 / T7.5

## Deliverable

`docs/security-exceptions.md` defines the required fields: identifier, package
and version, advisory, severity, owner, reachability evidence, compensating
control, expiry and review trigger.

`processing/roadmap/security-advisories.md` is the advisory log. It records the
resolved `tmp` high and the accepted PostCSS high (`EX-001`), plus the moderate
development findings that stay below the gate.

`scripts/security/audit-gate.cjs` and
`scripts/security/verify-g5-residual-chains.cjs` enforce the exception expiry
and the development-only lock proof.
