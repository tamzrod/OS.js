# T4.4 — Migrate the root browser build

**Goal:** G4  
**Status:** P4 implemented; P5 review pending

## Scope

Migrate the root configuration to Webpack 5 asset modules and maintained HTML/CSS/minification plugins. Preserve template/favicon/font/image/chunk behavior, source maps, and `OSJS_VERSION` injection.

## Exit condition

A clean production root build succeeds on Node 26 without a legacy provider and matches the normalized reference contract or records an explicitly approved difference.

## Verification

Retain build logs, normalized inventories, HTML/CSS/asset checks, chunk resolution, hashes, and repeat-build determinism results.

## Implementation

- Migrated root images/fonts to Webpack 5 asset modules and CSS minimization to `css-minimizer-webpack-plugin`.
- Preserved `osjs` and `vendors~osjs` JavaScript/CSS chunks, favicon, fonts, images, maps, title, and HTML references.
- Bound build/watch commands to the shared deterministic wrapper.
- Produced two identical Node 26 production contracts without a legacy-provider override.
- Recorded approved modern-minifier/content-hash/license-sidecar differences in `docs/evidence/security-build/t4.4-root-build-migration.md`.
