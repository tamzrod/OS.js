# T4.4 — Migrate the root browser build

**Goal:** G4  
**Status:** Blocked by T4.3

## Scope

Migrate the root configuration to Webpack 5 asset modules and maintained HTML/CSS/minification plugins. Preserve template/favicon/font/image/chunk behavior, source maps, and `OSJS_VERSION` injection.

## Exit condition

A clean production root build succeeds on Node 26 without a legacy provider and matches the normalized reference contract or records an explicitly approved difference.

## Verification

Retain build logs, normalized inventories, HTML/CSS/asset checks, chunk resolution, hashes, and repeat-build determinism results.
