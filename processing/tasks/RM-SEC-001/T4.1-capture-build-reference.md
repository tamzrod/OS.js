# T4.1 — Capture the build reference contract

**Goal:** G4  
**Status:** P4 implemented; P5 review pending

## Scope

Record exact source, configuration, runtime, dependency, and committed-output identities for all five build configurations. Capture a root reference artifact in an isolated compatibility runtime if necessary, without any legacy OpenSSL flag, then normalize HTML, JS globals/formats, CSS, chunks, assets, source maps, and smoke observations.

## Exit condition

A retained, reproducible reference contract can detect meaningful behavior drift without requiring byte identity across the toolchain migration.

## Verification

- Hash every input and retained output.
- Prove the reference command contains no legacy-provider override.
- Replay inventory/contract extraction independently.
- Record limitations of any compatibility runtime; its output is not release evidence.
