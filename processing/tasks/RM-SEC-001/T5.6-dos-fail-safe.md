# T5.6 — Prove denial-of-service inputs fail safely

**Roadmap:** RM-SEC-001 / G5 / T5.6
**Depends on:** T5.5

## Changes

`scripts/security/g5-dos-boundaries.test.cjs` runs the hostile-input probe in a
child Node process capped at `--max-old-space-size=64` and requires:

- a 200,000-level object is rejected as `UnsafeObjectInputError`;
- 50,000 keys and an 8 MiB string are handled correctly;
- malformed JSON fails as `SyntaxError`;
- no server or socket resource is active after loading the shipped bundle;
- the process exits 0 with no heap-out-of-memory or allocation failure;
- the whole probe finishes under 15 seconds.

The probe finished in about 271 ms locally, so the limits leave a wide margin
for slower CI runners.
