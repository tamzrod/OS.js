## Scope

- Point `@osjs/client` at the fork-owned local package using the selected deterministic package mechanism.
- Regenerate the root lockfile only under Node 26.13.0/npm 11.20.0.
- Compare the normalized graph against the G1 baseline.

### Out of scope

- G3 merge changes or G5 server hardening.
- Publishing the forked package.

- Root client bootstrap/config only if required for explicit migration handling.
- `README.md` and security migration documentation.
- `docs/evidence/security-cookie/` — normalized graph comparison and command logs.

## Steps

1. Record pre-change manifest, lockfile, and graph hashes.
