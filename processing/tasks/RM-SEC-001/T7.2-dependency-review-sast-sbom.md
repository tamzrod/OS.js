# T7.2 — Dependency review, secret scanning, SAST and SBOM

**Roadmap:** RM-SEC-001 / G7 / T7.2

## Deliverables

- Lockfile dependency review: `scripts/security/review-lockfile.cjs` compares
  the pull request lock against its base, fails on any new production package
  or version change that is not in the reviewed allowlist, and confirms every
  allowlisted package remains. GitHub's dependency-review API returns
  `Forbidden` for this repository, so the gate is implemented locally and runs
  in the same required workflow.
- Secret scanning: `scripts/security/scan-secrets.cjs` scans every tracked text
  file for private keys, AWS, GitHub, Slack, Google and npm token shapes.
- SAST: `.github/workflows/codeql.yml` runs CodeQL `javascript-typescript` with
  `security-extended` queries, pinned to
  `74c1aea9df7c0f02e9b7bfe4a8935abf2e5e3aa6`.
- SBOM: the continuous workflow installs `@cyclonedx/cyclonedx-npm@7.0.0` in an
  isolated directory and emits full and production CycloneDX 1.6 documents.
