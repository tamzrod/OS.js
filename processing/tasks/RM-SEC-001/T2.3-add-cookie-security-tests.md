## Scope

### In scope

- Test login success, failure, startup, logout, and standalone behavior.
- Instrument `document.cookie`, local storage, session storage, and IndexedDB boundaries.
- Test own and inherited `enabled` values, JSON `__proto__`, `constructor`, `prototype`, getters, symbols, nested fields, and arbitrary custom login values.
- Assert the intended post-remediation behavior while proving the legacy baseline fails for the expected reason.
- Preserve current event, callback, and adapter call-order expectations.

### Out of scope

- Production code changes.
- Dependency removal or lockfile changes.
- Server session redesign.
- Tests for unrelated merge surfaces assigned to G3.

## Change surface

- `vendor/osjs-client/__tests__/` — authentication security tests and fixtures.
- `docs/evidence/security-cookie/` — red-test command, output, and expected-failure classification.

## Steps

1. Create deterministic browser API spies without real credential persistence.
2. Capture the existing authentication event and adapter sequence.
3. Add persistence-prohibition assertions.
4. Add hostile configuration and login-value cases.
5. Run against the unchanged baseline and record only the expected failures.

## Exit condition

The test suite deterministically fails on legacy credential persistence and unsafe legacy enablement while passing unchanged compatibility assertions, with no production implementation change.
