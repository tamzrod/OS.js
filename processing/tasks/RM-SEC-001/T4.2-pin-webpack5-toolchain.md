# T4.2 — Pin one maintained Webpack 5 toolchain

**Goal:** G4  
**Status:** Blocked by T4.1

## Scope

Install the exact reviewed Webpack 5, CLI, HTML, CSS extraction/minimization, Sass, CSS, Babel, and source-map toolchain at the root. Replace file-loader with asset modules and remove root/package-local paths that retain Webpack 4 or obsolete plugins.

## Exit condition

The lock contains one approved build family and no Webpack 4, webpack-cli 3, html-webpack-plugin 3, optimize-css-assets-webpack-plugin, file-loader, or equivalent obsolete package-local chain.

## Verification

Retain before/after lock inventories, exact versions/integrities, `npm ls` results, and full/production audit deltas.
