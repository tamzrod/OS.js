# T8.1 — Clean-room release evidence

**Roadmap:** RM-SEC-001 / G8 / T8.1

## Procedure

On a clean checkout of the release candidate, with pinned Node 26.13.0 and npm
11.20.0:

1. `npm ci --ignore-scripts`;
2. `npm test`;
3. `npm run package:discover`;
4. `npm run build`;
5. full and production audit JSON;
6. production and full CycloneDX SBOM;
7. G2, G3, G4 evidence workflows and the continuous/CodeQL gates.
