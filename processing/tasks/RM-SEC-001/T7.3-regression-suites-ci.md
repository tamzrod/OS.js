# T7.3 — Security regression suites in CI

**Roadmap:** RM-SEC-001 / G7 / T7.3

## Deliverable

The continuous workflow builds the browser artifact, then runs
`node --test scripts/security/g3-*.green.test.cjs scripts/security/g5-*.test.cjs scripts/security/g6-*.test.cjs`. The red reproduction test is excluded because it asserts the vulnerable pre-fix behavior. The green suites cover:

- cookie persistence and policy tests;
- safe-object prototype-pollution tests;
- G5 startup, registration, auth, proxy, watcher and production-graph tests;
- G5 shipping-boundary, malformed-input and constrained-heap DoS tests;
- G6 artifact-allowlist and static-host tests.

Results are written to `security-output/security-tests.log`.
