# T5.3 — Remove residual parsing, WebSocket, glob, UUID, archive and metadata chains

**Roadmap:** RM-SEC-001 / G5 / T5.3
**Position:** P4 implementation
**Depends on:** T5.2 (server removed from the production graph)

## Scope decision

Every dependency chain named by T5.3 belongs to the Node server surface:
HTTP and query parsing (`express`, `body-parser`, `qs`), WebSocket (`ws`),
globbing (`glob`, `minimatch`, `picomatch`, `brace-expansion`), UUID, archive
handling, and metadata processing. T5.2 removed that surface from the root
production graph and the browser distribution is the shipping boundary.

The production SBOM now contains 32 recursively listed browser components and no server chain.
Upgrading an unreachable server chain would add no shipped security value, so
T5.3 instead proves the absence and reduces the development tool chain that
remains in the repository.

## Changes

- `npm audit fix` (no force) updated the development graph within declared
  ranges. The lock resolves 41 package versions, including `@osjs/cli` 3.2.0,
  `ajv` 6.15.0, `brace-expansion` 1.1.22, `braces` 3.0.3, `flatted` 3.4.4,
  `glob-parent` 5.1.2, `micromatch` 4.0.8, `minimatch` 3.1.5, `picomatch` 2.3.2,
  `trim-newlines` 3.0.1, and `word-wrap` 1.2.5. No manifest range changed.
- Added an `overrides` entry pinning `tmp` to `0.2.7`, which removes the
  symlink path-traversal finding in the development CLI editor helper.
- Rejected a `postcss` override: stylelint 13 and `postcss-syntax` fail against
  PostCSS 8, so the remaining PostCSS 7 copy cannot be patched without a
  separate stylelint migration.
- Added `scripts/security/verify-g5-residual-chains.cjs`. It requires a zero
  production audit, scans the production SBOM for the server parsing,
  WebSocket, glob, UUID, archive and metadata chain names, proves every
  remaining full-tree high is development-only in the lock, enforces an expiry
  for the recorded PostCSS exception, and scans the built browser distribution
  for server runtime markers.
- Wired the verifier into the G4 evidence runner so clean retained evidence
  covers it.
