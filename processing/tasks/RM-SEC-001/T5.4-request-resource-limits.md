# T5.4 — Record shipping-boundary request and resource limits

**Roadmap:** RM-SEC-001 / G5 / T5.4
**Depends on:** T5.2, T5.3

## Scope decision

The shipped artifact is static. It has no HTTP server, request parser, upload
handler, archive extractor or decompression endpoint, so application-level
request body, header, connection and decompression limits do not exist to
configure. The mission explicitly rejects inventing a production requirement
for the legacy Node server.

T5.4 therefore records the limits at the boundary that actually parses
requests: the static host. `docs/g5-static-host-limits.md` defines methods,
body, header, request-line, timeout, keep-alive, connection, compression and
upload rules, and the client-side safe-object bounds that apply inside the
browser.

## Verification

- `scripts/security/g5-shipping-boundary.test.cjs` asserts that `dist/`
  contains no native addon, no package manifest with dependencies or scripts,
  no server request/upload/archive marker, and no active listener or socket
  after the shipped common bundle is loaded.
- The test runs in the G5 workflow and in G4 retained evidence.
