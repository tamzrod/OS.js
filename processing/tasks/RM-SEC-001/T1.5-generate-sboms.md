## Purpose

Generate traceable full and production-only CycloneDX JSON SBOMs for the verified baseline without adding a new generator dependency.

## Inputs

- Completed evidence contract from T1.2.
- Migrated and verified lockfile from T1.3.
- npm 11.20.0 native `npm sbom` capability.

## Dependencies

- Satisfied: T1.3 completed and passed P5 review. T1.5a approved pinned `@cyclonedx/cyclonedx-npm@7.0.0` with explicit toolchain binding, exact known-error filtering, and independent validation. T1.4 is not a dependency.

## Scope

### In scope

- Generate full and `--omit=dev` CycloneDX application SBOMs.
- Validate JSON structure, root component identity, dependency counts, and provenance.
- Hash both outputs and record them in the evidence manifest.
- Commit a concise summary under the evidence contract.

### Out of scope

- Adding an SBOM package to project dependencies.
- Vulnerability remediation or policy decisions.
- Signing or externally publishing SBOMs unless the evidence contract already requires it.

## Change surface

- CI evidence workflow or scripts defined by T1.2.
- `docs/evidence/security-baseline/` — SBOM summary and manifest entries.
- No manifest or lockfile changes are allowed.

## Steps

1. Verify toolchain, commit, and lockfile identity.
2. Generate full CycloneDX JSON with `sbom-type=application`.
3. Generate production-only CycloneDX JSON with `--omit=dev`.
4. Validate both documents and compare their root identity.
5. Hash outputs, update the evidence manifest, and confirm no source drift.

## Exit condition

Valid, hashed full and production CycloneDX SBOMs identify the same baseline application and can be traced to the exact source commit, lockfile, Node version, npm version, and generation command.

## Verification

```sh
npm sbom --sbom-format=cyclonedx --sbom-type=application
npm sbom --omit=dev --sbom-format=cyclonedx --sbom-type=application
node -e "JSON.parse(require('fs').readFileSync(process.argv[1], 'utf8'))" <sbom-json>
git diff --exit-code -- package.json package-lock.json
git diff --check
```
