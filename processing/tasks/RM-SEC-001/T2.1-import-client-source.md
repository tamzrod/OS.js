## Purpose

Create a fork-owned, maintainable source baseline for the exact client represented by `@osjs/client@3.7.1`, with complete provenance and no security behavior changes.

## Inputs

- [`P1 G2 analysis`](../../../docs/p1-g2-cookie-risk-analysis.md).
- [`P2 G2 plan`](../../../docs/p2-g2-safe-auth-persistence-plan.md).
- Locked npm artifact integrity `sha512-Ov99zmdlzD2uOaVPpKy4xD2WA45wtTCgplDbgt3qzhyfU7j70fJwlMJ3SWX3xCc2lFvf2o7AQBczHdPxGpmQdA==`.

## Dependencies

- Satisfied: P1 and P2 G2 completed.

## Scope

### In scope

- Resolve the authoritative upstream repository tag and commit for npm version 3.7.1.
- Import the tagged client source, package metadata, tests, build configuration, license, and required assets into `vendor/osjs-client`.
- Record upstream URL, commit, tag, npm integrity, import timestamp, file inventory, and deliberate exclusions.
- Compare imported source and its build metadata with the published npm tarball and source map.
- Keep the root manifest and lockfile byte-identical.

### Out of scope

- Editing authentication behavior.
- Removing `js-cookie`.
- Changing build dependencies or root dependency resolution.
- Rebuilding or publishing the client.

## Change surface

- `vendor/osjs-client/` — exact attributed upstream source baseline.
- `vendor/osjs-client/UPSTREAM.md` — provenance, integrity, import method, and exclusions.
- `docs/evidence/security-cookie/` — import inventory and comparison evidence.

## Steps

1. Resolve the upstream 3.7.1 tag and immutable commit.
2. Verify the upstream license and npm tarball integrity.
3. Import source without upstream Git metadata or generated dependency directories.
4. Generate a deterministic file inventory with hashes.
5. Compare package identity, public entry points, and source-map sources with the npm artifact.
6. Confirm the root dependency graph is unchanged.

## Exit condition

The repository contains an attributed, hash-inventoried client 3.7.1 source baseline whose relationship to the locked npm artifact is documented, with no authentication or root dependency changes.

## Verification

```sh
sha256sum package.json package-lock.json
git diff --check
node scripts/security/verify-client-import.js
```

## Rollback boundary

Remove only the newly imported `vendor/osjs-client` tree, its verifier, and its import evidence; no root dependency file should require restoration.
