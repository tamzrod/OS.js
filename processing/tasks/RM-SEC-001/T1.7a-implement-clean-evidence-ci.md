## Purpose

Turn the reviewed development-evidence commands into one clean-checkout CI workflow that validates source identity, preserves real exit codes and expected findings, validates manifests, and uploads the complete G1 artifact set with durable retention.

## Inputs

- Evidence contract and validator from T1.2.
- Lockfile inventory and comparison controls from T1.3.
- Audit capture helper from T1.4.
- Approved pinned SBOM controls from T1.5/T1.5a.
- Dependency classifier and expected build behavior from T1.6.

## Dependencies

- Satisfied: T1.1–T1.6 completed and passed development-evidence review.

## Scope

### In scope

- Add a dedicated manually runnable CI workflow using Node 26.13.0/npm 11.20.0.
- Require a clean checkout and record the actual CI commit and lockfile hashes.
- Run install, full/production audits, full/production SBOMs, classification, package discovery, and expected build capture.
- Reject unexpected command failures or diagnostics.
- Validate all evidence manifests and artifact hashes.
- Upload raw evidence with the maximum practical configured retention.
- Keep project manifest and lockfile byte-identical.

### Out of scope

- Pushing a branch or triggering remote CI.
- Accepting findings or fixing dependencies.
- Making Webpack build successfully.
- Changing runtime dependencies.

## Exit condition

The repository contains a reviewable CI workflow and supporting harness that can produce the complete clean G1 evidence set from a committed checkout, fail closed on unexpected results, and retain raw artifacts.
