# T4.5 — Verify browser behavior and build policy

**Goal:** G4  
**Status:** Blocked by T4.4

## Scope

Serve the production artifact from a clean static host and verify bootstrap, package metadata, chunks, CSS, fonts/images, CSP behavior, and the explicit source-map policy. Scan configuration, scripts, CI, and documentation for legacy-provider workarounds.

## Exit condition

Browser smoke tests pass with no missing or policy-violating resources, and no `--openssl-legacy-provider` occurrence or equivalent environment override exists.

## Verification

Use a bounded static server, retained network/console observations, CSP checks, artifact scans, and repository-wide workaround scans.
