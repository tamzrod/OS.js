## Purpose

Establish a deterministic build-and-API baseline for the imported client before any security behavior changes.

## Inputs

- Reviewed T2.1 source import, provenance manifest, and npm reference artifact.

## Dependencies

- Satisfied: T2.1 passed P5 provenance and equivalence review.

## Scope

### In scope

- Install the imported client's exact development graph in isolation.
- Run its tests, lint, and build commands under explicitly recorded toolchains.
- Compare package name/version, exports, type declarations, CSS/assets, and JavaScript entry points with npm 3.7.1.
- Record every reproducible and non-reproducible difference.
- If Node 26 exposes a build blocker, document the smallest bounded prerequisite without using `--openssl-legacy-provider`.

### Out of scope

- Cookie or authentication changes.
- Root-project dependency integration.
- General G4 build modernization.
- Accepting unexplained generated-output drift.

## Change surface

- `vendor/osjs-client/` — only reproducibility scripts or metadata needed for its baseline build.
- `scripts/security/verify-client-baseline.js` — deterministic comparison.
- `docs/evidence/security-cookie/` — logs, hashes, export inventory, and blocker evidence.

## Steps

1. Freeze the client build toolchain and install command.
2. Run tests/lint/build without unsafe runtime flags.
3. Inventory public exports and packaged files.
4. Compare generated output against the published reference.
5. Classify differences as source-, environment-, or toolchain-derived.
6. Record a pass or a bounded loop-back prerequisite.

## Exit condition

The imported client can be rebuilt and its public/package surface compared deterministically, or an evidence-backed build prerequisite is isolated for P5 loop-back without modifying authentication.

## Verification

```sh
node scripts/security/verify-client-import.js
node scripts/security/verify-client-baseline.js
git diff --check
```

## Rollback boundary

Revert only client-local build metadata, verifier code, and T2.2 evidence; the T2.1 source baseline remains intact.
