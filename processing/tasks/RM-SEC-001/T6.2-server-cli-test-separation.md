# T6.2 — Separate server, CLI, examples, tests and build tools from the deliverable

**Roadmap:** RM-SEC-001 / G6 / T6.2
**Depends on:** T6.1

## State

- The root production graph is browser-only; `@osjs/server` and the server
  runtime chains were removed in T5.2 and T5.3.
- `dist/` contains only build output, fonts, and ten reviewed package links
  under `apps/`, `themes/`, `icons/` and `sounds/`. Each link resolves to
  `node_modules/@osjs/<package>/dist` or `vendor/osjs-<package>/dist`.
- No `src/`, `vendor/`, `scripts/`, `test/`, `tests/` or `node_modules/` path
  appears in the artifact, and no `*.test.js` or `*.spec.js` file ships.
- The server, CLI, build tooling and test dependencies stay in `devDependencies`
  or in the vendored server's own lock, outside the production graph.

## Verification

`g6-browser-artifact.test.cjs` walks the artifact, rejects unexpected files and
links, and rejects any source, server, test or dependency tree.
