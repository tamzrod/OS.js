# T7.1 — CI audit jobs with high-severity thresholds

**Roadmap:** RM-SEC-001 / G7 / T7.1

## Deliverable

`.github/workflows/security-continuous.yml` captures full and production audit
JSON on every push, pull request and manual run, then runs
`scripts/security/audit-gate.cjs`.

The gate fails on:

- any production high or critical finding;
- any full-tree critical finding;
- any full-tree high finding without a recorded development-only exception,
  a lock proof that every copy is `dev: true`, and an unexpired date.

The only current full-tree high is `postcss`, recorded as `EX-001`.
