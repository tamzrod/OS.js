# T6.4 — Run the artifact in a clean static-host environment

**Roadmap:** RM-SEC-001 / G6 / T6.4
**Depends on:** T6.3

## Deliverable

`scripts/security/g6-static-host.test.cjs` starts a minimal static host on
`127.0.0.1` with an ephemeral port. The host:

- serves only `GET` and `HEAD`; every other method gets `405`;
- resolves files under `dist/` and the reviewed package link targets only;
- rejects traversal outside those roots.

The test fetches `index.html`, `osjs.js`, `metadata.json` and
`apps/FileManager/main.js`, checks status, content type and byte equality, and
requires `404` for `package.json`, `src/server/index.js`, encoded traversal and
the vendored server manifest.

This is a functional smoke test of the static deliverable, not a deployment
server. It exists only inside the test process.
