# T6.3 — Fail the build on forbidden packages or files

**Roadmap:** RM-SEC-001 / G6 / T6.3
**Depends on:** T6.1, T6.2

## Deliverable

`scripts/security/g6-browser-artifact.test.cjs` is the artifact-content gate.
It fails when:

- a file is outside the root file list, the font pattern or the hashed image
  pattern;
- a dotfile other than the documented `dist/.gitignore` placeholder appears;
- a link points outside a reviewed package or to a package outside the
  allowlist;
- any `src`, `vendor`, `scripts`, `test`, `tests` or `node_modules` path ships;
- a test or spec file ships;
- the production SBOM differs from the allowlist;
- the root manifest declares a non-allowlisted runtime dependency;
- `index.html` references a remote or parent-escaping asset;
- `metadata.json` lists a package without a corresponding artifact link.

The test runs in the G5 workflow and in G4 retained evidence, after the build.
