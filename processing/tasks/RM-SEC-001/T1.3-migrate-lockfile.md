- Create normalized before/after dependency inventories.

- Audit remediation.

1. Verify the source lockfile checksum and clean source identity.
2. Generate the normalized before-inventory.
3. Migrate using only the pinned Node/npm environment.
4. Generate the normalized after-inventory and compare it.

6. Run two clean installations, checking the lockfile checksum after each.
