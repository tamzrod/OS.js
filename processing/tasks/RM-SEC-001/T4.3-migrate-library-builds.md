# T4.3 — Migrate fork-owned library builds

**Goal:** G4  
**Status:** Blocked by T4.2

## Scope

Migrate common, client, dialogs, and settings in dependency order to the shared toolchain. Preserve CommonJS, named UMD globals, the `OSjs` external, CSS/assets, and source maps.

## Exit condition

Every standalone package builds on Node 26 without OpenSSL overrides, passes existing security/compatibility suites, and satisfies its recorded output contract.

## Verification

Inspect exports/globals/externals, compare normalized inventories, resolve every emitted asset URL, and run package tests after each bounded migration.
