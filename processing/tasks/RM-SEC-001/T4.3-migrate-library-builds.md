# T4.3 — Migrate fork-owned library builds

**Goal:** G4  
**Status:** P4 implemented; P5 review pending

## Scope

Migrate common, client, dialogs, and settings in dependency order to the shared toolchain. Preserve CommonJS, named UMD globals, the `OSjs` external, CSS/assets, and source maps.

## Exit condition

Every standalone package builds on Node 26 without OpenSSL overrides, passes existing security/compatibility suites, and satisfies its recorded output contract.

## Verification

Inspect exports/globals/externals, compare normalized inventories, resolve every emitted asset URL, and run package tests after each bounded migration.

## Implementation

- Migrated all four configurations to Webpack 5 library/minimizer/asset APIs.
- Bound package build scripts to a shared wrapper that fixes both `NODE_ENV` and
  Webpack mode before invoking the root-pinned Webpack binary.
- Rebuilt and retained dependency-ordered package outputs under Node 26 without an OpenSSL override.
- Added `scripts/security/verify-g4-library-builds.cjs`; G3 regressions, 12 common tests, and 321 client tests pass.
- Detailed hashes and warning classification are recorded in `docs/evidence/security-build/t4.3-library-build-migration.md`.
