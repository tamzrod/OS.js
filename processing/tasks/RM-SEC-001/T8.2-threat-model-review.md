# T8.2 — Deployment threat-model review

**Roadmap:** RM-SEC-001 / G8 / T8.2

## Deliverable

`docs/g8-threat-model-review.md` reviews assets, trust boundaries, cookies,
prototype pollution, malformed input, resource exhaustion, artifact leakage,
unreviewed dependencies, secrets, `postMessage`, static-host traversal, reverse
proxy and browser security headers.

The shipping boundary remains the browser-only static distribution. The Node
server stays development-only and fail-closed.
