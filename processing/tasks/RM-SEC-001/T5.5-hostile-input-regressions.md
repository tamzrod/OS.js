# T5.5 — Add malformed and oversized input regressions

**Roadmap:** RM-SEC-001 / G5 / T5.5
**Depends on:** T5.2, T5.4

## Changes

`scripts/security/g5-hostile-input.test.cjs` exercises the shipped
`vendor/osjs-common` bundle, not a test double:

- nesting beyond 64 levels is rejected with `UnsafeObjectInputError`, and a
  100,000-level input is rejected in under one second;
- malformed stored JSON fails with `SyntaxError` in under one second;
- a parsed `__proto__` payload is rejected and `Object.prototype` stays clean;
- 50,000 keys, a 100,000-element array and an 8 MiB string complete with the
  expected shape and bounded time;
- a 10,000-segment dotted path fails closed in under three seconds.

HTTP header, fragment and upload cases are covered by absence: the shipping
artifact has no parser or upload endpoint, as asserted by T5.4. The
development server is not a shipping target.
