# T6.1 — Define browser entry points and the explicit dependency allowlist

**Roadmap:** RM-SEC-001 / G6 / T6.1
**Depends on:** G5

## Deliverable

`scripts/security/browser-runtime-allowlist.json` records the reviewed browser
artifact:

- 31 runtime package identities (`name: version`), matching the production
  SBOM exactly;
- the root files emitted by the build (`index.html`, `osjs.js`, vendor bundles,
  source maps, metadata, favicon and the repository's `dist/.gitignore`
  placeholder);
- the asset directories (`apps`, `fonts`, `icons`, `sounds`, `themes`);
- the hashed Webpack image pattern.

The entry point is `index.html`, which loads `vendors~osjs.js` and `osjs.js`
plus the two stylesheets, all local.

## Verification

`g6-browser-artifact.test.cjs` compares the production SBOM against the
allowlist exactly, so any new runtime package requires a deliberate allowlist
change. It also checks the root manifest declares only allowlisted packages.
