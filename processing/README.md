# Processing

This directory contains active processing artifacts used to move the fork from its current state to an approved release state. Each roadmap goal follows the loop defined in [`PROCESS.md`](PROCESS.md): P1 Understand the Problem, P2 Design the Approach, P3 Break Down the Work, P4 Execute One Task, and P5 Review and Continue. Coordinates such as `P1 G1` identify the process stage and goal currently in focus.

- [`roadmap/`](roadmap/) contains plans made up of ordered goals.
- [`tasks/`](tasks/) contains independent micro-tasks produced by scope segregation.
- Evidence and durable technical analysis belong in [`../docs/`](../docs/).
- Source changes belong in the normal project tree, not in this directory.

Roadmaps describe intended and active work. They are not substitutes for test results, audit evidence, or release approval.
