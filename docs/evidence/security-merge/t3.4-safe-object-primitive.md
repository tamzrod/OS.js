# T3.4 safe-object primitive evidence

**Toolchain:** Node `v24.16.0`, npm `11.13.0` (verification replay; the retained package lock is unchanged)
**Result:** 12 focused security tests pass; package lint has zero errors; production bundle succeeds

## Implemented contract

Fork-owned `@osjs/common` now publicly exports `UnsafeObjectInputError`, `assertSafeObject`, `safeMerge`, and `safeSetPath` with matching TypeScript declarations. The implementation:

- accepts only ordinary own data properties and never reads accessors;
- rejects `__proto__`, `prototype`, and `constructor` recursively;
- rejects symbol properties, inherited object shapes, unsupported prototypes, cycles, and excessive depth;
- requires an explicit `replace` or `concat` array policy;
- preserves functions only when a caller explicitly opts in;
- does not mutate input objects or invoke ambient prototype setters; and
- builds ordinary output objects with `Object.defineProperty`.
