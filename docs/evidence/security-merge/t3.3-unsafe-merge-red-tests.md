## Bound contract

The red suite machine-checks all 11 production merge call sites across client, common, dialogs, server, and settings application before running hostile probes against the exact locked merge implementations and adjacent copy/path algorithms.

Passing baseline assertions prove that the source inventory remains current and ordinary nested override behavior is reproduced. Expected failures isolate:

- nested `constructor.prototype` input is not rejected;
- getters are consumed instead of rejected descriptor-safely;
- inherited, symbol-keyed, and unsupported instance inputs are not rejected;
- cycles terminate with an uncontrolled `RangeError` instead of a typed bounded-input error;
- array behavior is implicit rather than policy-selected;
- dialogs-local `deepmerge@2.2.1` accepts parsed `__proto__` and poisons returned-object inheritance;
- the local-storage accumulator accepts a reserved storage key;
- the settings dotted-path builder accepts a reserved segment.

The dotted-path probe always removes its temporary `Object.prototype` sentinel in `finally`. No test leaves global prototype state behind.
