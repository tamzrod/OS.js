## Execution results

- Isolated ESLint passed with zero errors: common 2 baseline warnings, dialogs 18, server 1, settings application 2.
- Dialogs and settings Stylelint passed.
- Server Jest passed 12 suites/90 tests under the retained Jest 26 runner supplied by the common baseline graph. The server manifest's `jest` script has no direct Jest dependency, so this missing upstream test-runner declaration is explicitly recorded rather than silently added to production source.
- Production Webpack builds passed on Node 26 without `--openssl-legacy-provider`: common 2 outputs, dialogs 3, settings application 2.
- A second production build reproduced every retained output byte-for-byte.
- Dry-run packages contain 7 common files, 7 dialogs files, 24 server files, and 6 settings-application files. Complete paths, sizes, integrities, lock identities, and output hashes are retained in `t3.2-baseline.json`.

## Published-output comparison

The tagged sources agree with published application source content, but JavaScript bundles and maps differ from registry output because upstream supplied no lock and the frozen baseline resolves later compatible build dependencies. Dialogs CSS is byte-identical. This is classified dependency/toolchain-derived drift; T3.3 tests target source behavior, and future comparisons use the retained exact locks and output hashes from this task.

## Verification

`node scripts/security/verify-merge-package-baselines.js` binds all four locks and seven retained distribution outputs to the machine evidence. P5 must perform a fresh-copy `npm ci`, rerun lint/tests/builds, and compare the second build and dry-run package inventories before accepting T3.2.
